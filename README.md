# PDF 활동지 채점기 (PDF Activity Grader)

이 프로그램은 교사용 정답지와 학생 제출물(스캔 이미지/PDF)을 비교하여 오타를 점검하고 점수를 산출하는 도구입니다.

## 주요 기능
- **OCR 텍스트 추출**: EasyOCR을 사용하여 한국어 및 영어 텍스트를 인식합니다.
- **오타 감지**: `difflib` 알고리즘을 사용하여 정답과 제출물 사이의 차이점을 분석합니다.
- **시각적 리포트**: 빠진 내용(빨간색 취소선)과 추가된/틀린 내용(파란색 굵게)을 시각적으로 표시합니다.

## 설치 및 실행 방법

### 1. 필수 의존성 설치
```bash
pip install -r requirements.txt
```

### 2. 실행
```bash
streamlit run app.py
```

## 사용 방법
1. 브라우저에서 열린 페이지 왼쪽의 **정답지** 칸에 기준이 되는 PDF를 업로드합니다.
2. 오른쪽의 **학생 제출본** 칸에 채점할 PDF를 업로드합니다.
3. **채점 시작** 버튼을 누르면 분석 결과가 출력됩니다. (Poppler 설치 없이 바로 실행 가능합니다.)
