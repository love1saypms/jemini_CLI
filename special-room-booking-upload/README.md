# 특별실 예약 시스템

Apache 2.4 + PHP 8.4 + MySQL용, 프레임워크 없는 PHP/PDO 웹 애플리케이션입니다.

## 업로드 및 설치

1. 웹호스팅 제어판에서 MySQL 데이터베이스와 **최소 권한의 전용 DB 사용자**를 만듭니다. 호스팅 DB 계정은 제어판에서 생성해야 하므로 이 소스가 임의로 만들 수 없습니다.
2. phpMyAdmin에서 실제 운영 DB(현재 오류 기준 `love1say`)를 먼저 클릭한 뒤 `database/schema-hosting.sql`을 가져옵니다. 이 파일은 DB 생성·선택 구문이 없어 공유 웹호스팅에서 안전합니다. `schema.sql`은 로컬 개발용입니다.
3. `config.php`에서 DB 호스트·포트·DB명·사용자명·비밀번호를 실제 값으로 변경합니다. 현재 보이는 `CHANGE_ME_DB_USER` 오류는 이 단계를 하지 않았다는 뜻입니다.

   ```php
   'host' => 'localhost',              // 호스팅 안내에 다른 값이 있으면 그 값 사용
   'name' => '제어판에서_만든_DB명',
   'user' => '제어판에서_만든_DB사용자',
   'pass' => '해당_DB사용자의_비밀번호',
   ```

   파일은 웹호스팅 파일 관리자에서 `/hosting/love1say/html/config.php`를 열어 수정할 수 있습니다. DB 계정·비밀번호는 애플리케이션 로그인 계정(`admin`)과 다른 값입니다.
4. `special-room-booking` 폴더 **안의 내용**을 웹 문서 루트(`public_html` 등)에 업로드합니다. Apache에서 `.htaccess`가 적용되는지 확인합니다.
5. HTTPS로 접속해 로그인하고, 초기 계정의 비밀번호를 즉시 변경합니다.

## 초기 애플리케이션 계정

| 역할 | 아이디 | 초기 비밀번호 |
| --- | --- | --- |
| 관리자 | `admin` | `password` |
| 교사 | `teacher1` | `password` |

두 계정 모두 첫 로그인 뒤 비밀번호 변경 화면으로 이동합니다. 초기 비밀번호는 공개된 설치용 값이므로 실제 운영 전 반드시 변경하세요. 관리자는 관리자 화면에서 교사·관리자 계정을 추가하거나 초기화할 수 있습니다.

## 기능

- 교사 로그인, 비밀번호 변경, 세션 재생성
- 날짜·특별실·교시 단위 예약 및 본인 예약 취소
- InnoDB의 고유 키로 동시 중복 예약 차단
- 관리자: 사용자·특별실·교시 추가, 활성/중지, 비밀번호 초기화
- 예약 취소/관리자 삭제의 감사 기록 보존

## 운영 확인

- PHP PDO MySQL 확장(`pdo_mysql`)을 활성화합니다.
- `config.php`의 `CHANGE_ME_*` 값이 남아 있지 않은지 확인합니다.
- 호스팅 PHP 오류 로그를 켜고, `display_errors`는 운영에서 끕니다.
- 예약 동시성은 두 브라우저/세션으로 같은 슬롯을 동시에 예약해 한 건만 성공하는지 확인합니다.
